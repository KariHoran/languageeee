# Languageeee

Приложение для планшетов на **React Native (Expo)** для изучения китайского и английского через чтение фанфиков. Весь интерфейс и объяснения — на **русском языке**.

## Запуск

```bash
npm install
npm start
```

Для обработки текстов через OpenAI создайте файл `.env`:

```
EXPO_PUBLIC_OPENAI_API_KEY=sk-...
```

## Структура

| Файл | Описание |
|------|----------|
| `src/types/index.ts` | TypeScript-интерфейсы |
| `src/services/aiService.ts` | Обработка текста через GPT-4o-mini |
| `src/services/storageService.ts` | Локальное хранилище (AsyncStorage) |
| `src/screens/ReaderScreen.tsx` | Экран чтения с интерактивными словами |
| `src/data/demoBook.ts` | Демо-книга для тестирования без API |

## ReaderScreen

- Интерактивные китайские слова с всплывающим окном (иероглифы, пиньинь, перевод)
- Кнопки **«Добавить в словарик»** и **«Уже знаю»**
- Раскрывающийся блок **«Грамматика в этом абзаце»**
- Переключатели русского и английского параллельного перевода
- Адаптивная вёрстка под планшет (ширина ≥ 768 px)
